AList File Manager — Privacy Policy

本文档为双语隐私政策。英文版在前，中文版在后。（This document is bilingual: English first, Chinese below.）

1. Overview

AList File Manager is a self-hosted file aggregation program that runs entirely on your own NAS device (TerraMaster TOS 7). The application itself does not collect, transmit, or share any personal data with the publisher or any third party. There are no analytics, no telemetry, no tracking, and no advertising SDKs.

2. Data stored on your device

DataLocationPurpose
User accounts (hashed passwords, preferences)/var/lib/alist/data.dbLocal login and per-user settings
Initial admin password/var/lib/alist/admin_password.txt (root-only, 0600)One-time first-login credential; delete after changing the password
Storage credentials you configure (OAuth/refresh tokens, keys)/var/lib/alist/data.dbConnect the cloud drives you add; never leaves the device
App configuration/var/lib/alist/config.json, /usr/local/alist/alist.envServer settings (listen address, port, database, optional services)
Search index, logs/var/lib/alist/Local full-text search and troubleshooting
Your filesThe storages you connectThe content you manage; not copied elsewhere by the app

All of this data stays on your device. It is never uploaded by the application to the publisher or any intermediary.

3. Your rights: access, correction, deletion

  • Access: log in to the web UI (all settings and storage mounts are visible there), or read the local files listed above as the NAS administrator.
  • Correction: change settings in the web UI or edit /usr/local/alist/alist.env at any time.
  • Deletion: remove accounts or storages in the web UI; apt remove (or App Center uninstall) keeps data, apt purge deletes /var/lib/alist entirely. No remote copy exists anywhere because nothing was ever uploaded.

4. Third-party network access (user-initiated only)

The application contacts external services only for operations you explicitly perform:

  • Storages you configure (cloud drives, WebDAV/S3 servers): requests go directly from your NAS to those services to list, read, upload and download files, using the credentials you provided. Data destinations are those of the respective providers.
  • Offline downloads / link previews: only when you submit a URL; the target server receives the request directly from your NAS.
  • Nothing else: no data is sent to the publisher, no update checks phone home, no crash reporting exists.

5. Accounts and children

The application has a purely local account system (admin and optional users, including a disabled-by-default guest). It serves your LAN through the TOS web port and does not knowingly process children's data.

6. Changes and contact

This policy ships inside the application package (/usr/local/alist/privacy-policy.html, also served at /alist/privacy-policy.html). For questions or reports: https://github.com/Moechz/alist (Issues). Upstream project: https://github.com/AlistGo/alist (AGPL-3.0).

AList File Manager — 隐私政策（中文）

1. 概述

AList File Manager 是完全运行在您自己的 NAS 设备（TerraMaster TOS 7）上的自托管文件聚合程序。应用本身不向发布者或任何第三方收集、传输、共享任何个人数据：无统计、无遥测、无跟踪、无广告 SDK。

2. 存储在您设备上的数据

数据位置用途
用户账号（密码哈希、偏好）/var/lib/alist/data.db本地登录与用户设置
初始管理员密码/var/lib/alist/admin_password.txt（仅 root，0600）首登凭据；修改密码后可删除
您配置的存储凭据（OAuth/刷新令牌、密钥）/var/lib/alist/data.db连接您自己添加的网盘；绝不离开设备
应用配置/var/lib/alist/config.json、/usr/local/alist/alist.env服务设置（监听地址、端口、数据库、可选服务）
搜索索引、日志/var/lib/alist/本地全文检索与排障
您的文件您连接的各存储您管理的内容；应用不另行复制

以上数据全部留在您的设备上，应用不会将其上传给发布者或任何中间方。

3. 您的权利：访问、更正、删除

  • 访问：登录网页界面（全部设置与存储挂载均可见），或以 NAS 管理员身份读取上述本地文件。
  • 更正：随时在网页界面修改设置或编辑 /usr/local/alist/alist.env。
  • 删除：在网页界面删除账号或存储；apt remove（或应用中心卸载）保留数据，apt purge 彻底删除 /var/lib/alist。因从未上传，任何远端都不存在副本。

4. 第三方网络访问（仅由您主动发起）

应用仅在您明确执行操作时访问外部服务：

  • 您配置的存储（网盘、WebDAV/S3 服务器）：由您的 NAS 直接向对应服务发起请求，用于列目录、读取、上传和下载文件，使用您提供的凭据；数据目的地为各服务商自身。
  • 离线下载 / 链接预览：仅在您提交 URL 时，目标服务器直接收到来自您 NAS 的请求。
  • 除此之外没有其他外联：不向发布者发送任何数据、无更新检查回连、无崩溃上报。

5. 账户与儿童

应用仅具备本地账号体系（admin 与可选用户，含默认禁用的访客账号），通过 TOS 网页端口服务您的局域网；不涉及儿童数据的处理。

6. 变更与联系

本政策随应用包分发（/usr/local/alist/privacy-policy.html，亦经 /alist/privacy-policy.html 提供）。问题或报告请至 https://github.com/Moechz/alist（Issues）。上游项目：https://github.com/AlistGo/alist（AGPL-3.0）。
